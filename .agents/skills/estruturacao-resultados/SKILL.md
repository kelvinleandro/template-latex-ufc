## Contexto

Esta skill fornece diretrizes para organizar, filtrar e apresentar dados na seção de **Resultados** de trabalhos científicos. O agente deve avaliar se o texto e os recursos visuais propostos pelo usuário atendem à lógica empírica, eliminando excessos e garantindo que os dados convirjam para a sustentação das conclusões.

---

## 1. O Que Incluir (Seleção Guiada pela Conclusão)

A seção de resultados não deve ser um relatório frio de todas as metodologias executadas no laboratório. O agente deve instruir o redator a filtrar os dados com base na seguinte lógica:

- **Apenas o Necessário:** Inclua estritamente os resultados que levam, sustentam ou justificam as conclusões do trabalho. Se um dado metodológico não se conecta com o discurso final, ele deve ser excluído.
- **Não é um Relatório de Esforço:** A ciência não avalia a quantidade de trabalho ("suor" ou espessura do documento), mas sim a qualidade do que se conclui a partir dele.
- **Honestidade Intelectual:** Não esconda dados significativos que contradizem as ideias iniciais do autor. A pesquisa empírica serve para testar hipóteses, não para defender ideias de estimação.

## 2. Decisões de Ênfase e Formato de Apresentação

Diferentes resultados possuem diferentes níveis de importância e devem receber níveis distintos de ênfase visual. O agente deve verificar a adequação da escolha do formato (Texto, Tabela ou Figura) conforme o tipo de pesquisa:

- **Figura (Maior Destaque):** O cérebro humano é extremamente visual, tornando as figuras a melhor opção para evidenciar comparações e relações. Devem ser a escolha prioritária para pesquisas de associação ou interferência entre variáveis.
- **Tabela (Destaque Intermediário):** Chama a atenção no texto, mas exige que o leitor faça contas mentais para entender diferenças. É o formato ideal para pesquisas descritivas (ex: caracterizar parâmetros sanguíneos de uma espécie), onde o número exato é o foco.
- **Texto (Menor Destaque):** A leitura linear esconde os números e torna as comparações difíceis. Se o resultado exige um parágrafo longo apenas para listar números, sugira a conversão para tabela.

## 3. Diretrizes para a Construção de Figuras

A construção do gráfico deve ser ditada pelo discurso da conclusão e seguir o bom senso para evitar poluição:

- **Evite Gráficos de Pizza:** O ser humano percebe diferenças lineares com muito mais facilidade do que diferenças bidimensionais (áreas). Prefira gráficos de colunas/barras para evidenciar magnitudes.
- **Sem Números Exatos nas Barras:** Evite sobrepor os valores exatos (com casas decimais) em cima de gráficos de barras. O gráfico serve para demonstrar visualmente as diferenças e proporções; se a precisão absoluta da casa decimal fosse o principal, o autor deveria usar uma tabela.
- **Unidades nos Eixos:** Posicione as unidades de medida (ex: mg, g, horas) diretamente nos eixos do gráfico em vez de deixá-las isoladas na legenda, facilitando a rápida interpretação visual pelo leitor.
- **Escalas Limpas:** Não coloque numerações excessivas (poluição) nos eixos. Use intervalos claros (ex: 0, 5, 10, 15) que deem a referência necessária sem sobrecarregar a imagem.
- **Barras de Desvio Obrigatórias:** Se o gráfico exibir médias estatísticas, a inclusão das barras de desvio padrão ou erro não é opcional, pois a variabilidade é crucial.

## 4. Gráficos de Linha vs. Gráficos de Barras

Há uma regra rígida baseada no fenômeno natural para escolher entre desenhar uma linha ou plotar barras independentes:

- **Gráficos de Linha:** Enfatizam **movimento** contínuo e dependência sequencial. Só devem ser utilizados se a variável do eixo X (abscissa) possuir uma **sequência natural** inalterável, como o "Tempo" (1h, 2h, 4h, 8h) ou idades.
- **Gráficos de Barras:** Devem ser usados se a ordenação das categorias no eixo X depender de uma **escolha arbitrária** do pesquisador (ex: comparar 5 cidades diferentes, ou comparar fumantes vs. não-fumantes). Unir essas barras com uma linha criaria uma ilusão de movimento que não reflete a realidade do fenômeno.

## 5. Interação Texto-Figura (Comunicação Direta)

A redação que acompanha figuras e tabelas não deve agir como um intermediário passivo:

- **Não Repita Dados Visuais no Texto:** É um erro listar exaustivamente em texto o que já está claro na imagem ou tabela.
- **Guiando o Olhar:** O texto deve dizer ao leitor exatamente qual comportamento ele deve observar na imagem, e não apenas jogar a referência de forma genérica.
- **Forma de Citar (Exemplo Prático):** Substitua frases ruins como _"A figura 1 mostra a relação entre X e Y"_ por declarações diretas, argumentativas e focadas no achado: _"Houve associação positiva entre X e Y (Figura 1)"_.
